# 🌍 Global Crisis Intelligence Dashboard

An AI-powered analytics system that tracks and analyzes global crises using real-time news data.

## 🚀 Features
- Live data extraction from global news APIs
- NLP-based keyword extraction
- Crisis classification (War, Economy, Climate)
- Sentiment analysis (Positive, Negative, Neutral)
- Custom Crisis Severity Score
- Data visualization for insights

## 🧠 Tech Stack
- Python (Pandas, Requests)
- NLP (NLTK)
- Sentiment Analysis (TextBlob)
- Data Visualization (Matplotlib)

## 📊 Key Insight
This project helps identify:
- Which global crisis is trending
- How severe it is
- What type of impact it may have

## 💡 Why this project?
Most dashboards show historical data.  
This system creates **real-time intelligence** for decision-making.

## 📁 Dataset
- global_news.csv
