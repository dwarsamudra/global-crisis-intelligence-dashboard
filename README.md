# 🌍 Global Crisis Intelligence Dashboard

An AI-powered system that analyzes global crises using real-time news data.

## 🚀 Features
- Live news data extraction
- NLP keyword extraction
- Crisis classification (War, Economy, Climate)
- Sentiment analysis
- Custom Crisis Severity Score
- Interactive dashboard (Streamlit)

## 🧠 Tech Stack
- Python
- Pandas
- NLTK
- TextBlob
- Streamlit
- Matplotlib

## 📊 Insights
- Identifies trending global risks
- Measures crisis severity
- Helps simulate real-world decision making

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
